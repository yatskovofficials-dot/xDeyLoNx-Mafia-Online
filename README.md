# 🎭 xDeyLoNx Mafia

Профессиональная онлайн-игра **Мафия** с общим чатом, рейтингом, валютой, магазином ролей, быстрым поиском игроков и полноценной админ-панелью.

## ✨ Возможности

- **Реальный мультиплеер** — комнаты, фазы ночь / день / голосование
- **10+ ролей**: Мирный, Мафия, Дон, Доктор, Шериф, Маньяк, Красотка, Адвокат и др.
- **Общий чат** + чат комнаты
- **⚡ Быстрый поиск** — мгновенный матчмейкинг
- **Игровая валюта** — монеты за победы и участие
- **Рейтинг** и таблица лидеров
- **Магазин** — роли и косметика за монеты
- **Анимация наград** после каждой игры
- **Профессиональный splash-экран** с анимациями
- **Админ-панель** (клик по логотипу 🎭 → пароль `9944191q`)
  - Выдача монет любому игроку
  - Назначение / снятие админов (сразу появляется префикс **АДМИН**)
  - Кик и бан
  - Список всех пользователей и онлайна
- **Кнопки Telegram**: [Канал](https://t.me/xDeyLoNxGame) и [Чат](https://t.me/ChatxDeyLoNx)
- **Реальный онлайн-счётчик** (без фейковых цифр)
- Аватар и ник из профиля (DiceBear или свой URL)
- JSON-база (без нативных модулей — легко деплоить)


## 💾 Сохранение прогресса

Баланс (🪙 монеты), рейтинг (⭐), победы, админ-права и инвентарь **сохраняются на сервере** в файл `server/data/mafia.json`.

- Вышел из игры → прогресс на месте
- Зашёл с тем же ником (или через Telegram) → всё на месте
- Не удаляй папку `server/data/` на хостинге

## 🚀 Запуск

```bash
git clone https://github.com/YOUR_USERNAME/xDeyLoNx-Mafia.git
cd xDeyLoNx-Mafia
npm install
npm start
```

Открой **http://localhost:3000**

Порт: `PORT=3000` (или любая переменная окружения `PORT`).

## 🎮 Как играть

1. Введи ник (аватар подтянется сам)
2. Нажми **«Быстрый поиск»** или создай комнату
3. Нажми «Готов» (минимум 4 игрока)
4. Хост запускает игру → получаешь роль
5. Ночью действуешь, днём обсуждаешь, голосуешь

### Награды
| Результат   | Монеты     | Рейтинг |
|-------------|------------|---------|
| Победа      | +50…80     | +25     |
| Участие     | +10        | −10     |
